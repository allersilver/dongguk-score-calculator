# 동국대 2026학년도 정시 환산점수 계산기

동국대학교 2026학년도 정시 모집요강의 수능 환산점수 산출 규칙을 Python으로 구현하고, 모집요강 산출 예시와 결과가 일치하는지 검증한 프로젝트

## 개요

| 항목 | 내용 |
|---|---|
| 기간 | 2026.11 |
| 도구 | Python, pandas, Jupyter Notebook |
| 범위 | 동국대 자연계열 유형①(수학과·통계학과·산업시스템공학과), 유형③(물리학과·전자전기공학부 등) |
| 출처 | 동국대학교 2026학년도 정시모집 요강 |

## 산출 규칙

- 국어·수학·탐구·영어: (점수 ÷ 200) × 1,000 × 반영비율
- 반영비율: 국어 0.25 / 수학 0.35 / 탐구 0.25 / 영어 0.15
- 영어는 등급별 환산표준점수, 한국사는 등급별 감점 적용
- 가산점: 수학 미적분·기하 선택 시 표준점수 3%, 유형③은 과학탐구 과목별 변환표준점수 3%

## 진행 과정

1. 모집요강의 반영비율, 등급표, 가산비율을 딕셔너리 하나에 정리하고 원문과 대조
2. 모집요강 예시 학생으로 영역별 점수 계산
3. 합계가 모집요강 값과 0.001 차이 → 반올림 시점 비교로 원인 확인
4. 유형①·③을 규칙 값(`탐구_과탐가산`)으로 분리해 하나의 함수로 계산
5. 모집요강 예시 2건을 `assert`로 자동 검증
6. 규칙이 다르게 적용되는 가상 학생 4명으로 테스트

## 핵심 결과: 반올림 시점에 따른 0.001점 차이

| 방법 | 계산 순서 | 합계 |
|---|---|---|
| A | 원래 점수 합산 후 합계만 반올림 | 714.383 |
| B | 영역별로 먼저 반올림 후 합산 | **714.384** (모집요강과 일치) |

- 수학 236.1275 → 236.128, 탐구 171.00575 → 171.006에서 생긴 올림이 누적되어 합계 자리가 바뀜
- 모집요강 규칙은 "환산점수 산출 시 소수점 넷째자리에서 반올림하여 적용"(p.37)으로, 자리수는 있지만 반올림 시점(영역별/합계)은 명시되어 있지 않음
- 모집요강 예시와 일치하는 B를 근거로, 동국대는 영역별로 먼저 반올림한 뒤 합산하는 방식으로 판단
- 정시는 환산점수 순으로 선발하므로 합격선 근처에서는 0.001점도 결과를 바꿀 수 있음 → 식뿐 아니라 계산 순서까지 원문과 맞춰야 함

## 가정과 한계

- 탐구 변환표준점수는 모집요강 예시값 사용 (실제 값은 수능 성적 발표 후 대학 공지)
- 사회탐구와 과학탐구의 변환표준점수를 같은 값으로 가정
- 유형②(과탐만 가산)는 해당 학과 목록 미확인으로 제외
